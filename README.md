# Yosef Klein, LMHC — Therapy Website

Static site for Yosef Klein, LMHC — licensed mental health counselor in Monsey, NY, working primarily with Orthodox Jewish men and adolescents. In-person sessions in Rockland County (Monsey, Spring Valley, Airmont, Chestnut Ridge) and virtual sessions across New York State. Sessions in Yiddish and English.

## Pages

- `index.html` — Home
- `about.html` — About / approach / training
- `who-i-help.html` — Who I Help
- `breathwork.html` — Psychosomatic Breathwork
- `faq.html` — FAQ (with FAQPage JSON-LD)
- `contact.html` — Contact form (FormSubmit → mail.klein@gmail.com)
- `thanks.html` — Post-submit thank-you (noindex)

## Stack

Hand-coded static HTML/CSS/JS — no framework, no build step.

- `assets/site.css` — shared design system (cream / sage / soft gold; Lora + Karla)
- `assets/site.js` — sticky header, mobile nav, scroll reveals
- Contact form via [FormSubmit](https://formsubmit.co) — **first submission requires clicking the activation email sent to mail.klein@gmail.com**
